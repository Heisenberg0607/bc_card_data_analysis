## 데이터: 실데이터 vs 추정·합성
- **실데이터**
  - BC 거래: Structure·Momentum·Confidence, 업종 구성
  - 법무부: 등록외국인 전국 총량·국적·추이
  - 외국인 군집 결과 (`외국인_시군구_유형.csv`)
  - 한국관광 데이터랩
    - 시군구: 평균 체류시간·숙박일수(229개, 일반구는 상위 시 값), 검색 상위 100 관광지(주소 → 시군구 100% 매칭)
    - 시도: 방문자수, 관광지출액, 목적지 검색건수, 방문자 증가율 (전남·광주 통합 표기 파일은 통합값 사용)
    - 전국: 외국인 방문자수(월), 국가별 방문 비율, 외국인 관광소비(월·업종·유형), 국가별 소비 비율, 간편결제
- **추정**: 시군구 외국인 방문자 = 데이터랩 전국 월평균 외국인 방문자(실측)를 BC 외국인 결제건수 × 관광지 사전가정 × Top100 관광지 수 × 숙박일수로 배분
- **합성(임의값)**: 등록외국인 시군구 분포, 주민등록인구, 업종별 점포·폐업률, 정책 사업명
  - 지역명 해시 기반이라 다시 만들어도 같은 값이 나온다. 화면에 `합성`/`추정` 표시.
- **데이터랩 파일 중 미사용**: '지역 방문자수_관광지출액 추세'·'국내관광 관심도 추이'(지역명 없음), '성·연령별방문자'(10대 인기지역 5곳만)
- 관광지출액은 원자료를 천원 단위로 가정해 환산했다.

## 진단 규칙 요약
- Structure: 외국인 결제금액 상위 30% = 대규모, TVD 중앙값 이상 = 고괴리
- Momentum: H1(1~3월)→H2(4~6월) CNT·ATV 변화를 **전국 외국인 추세 대비**로 보정 (1~6월 계절성 제거), ±5%
- Confidence: 3·2·1개월 블록 방향 일치 여부, 외국인 결제 20억 미만은 1단계 하향
- Context: Visitor Intensity(전국 평균=1) ≥ 2 → 방문형, 그 외 정주형
- 체류특성: 숙박일수 상위 25% = 숙박 체류형, 체류시간 하위 25% = 단시간 방문형
- 외부 타당성: BC 외국인 결제건수와 데이터랩 외국인 방문자수의 월별 상관 r = 0.95
